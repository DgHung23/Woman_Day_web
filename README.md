## 🌟 Điểm nổi bật & Tính năng (Features)

- 🌸 **Vườn hoa phát sáng huyền ảo**: Hiệu ứng nở rộ CSS 3D rực rỡ trong đêm, tối ưu cho cả máy tính lẫn màn hình dọc điện thoại di động (`100dvh`).
- 🤖 **Bộ nhận diện thương hiệu ARL**: Tích hợp Logo ARL đã được xử lý tách nền trong suốt, tối ưu hiển thị Dark Mode với hiệu ứng Neon Cyan/Blue sang trọng.
- 💻 **Cyber Code & Terminal 20/10**: 
  - Các đoạn code & mã máy đa ngôn ngữ (**Python, ROS 2 / C++, Rust, x86_64 Assembly, Arduino C, SQL**) chúc mừng 20/10 bay lơ lửng ở hậu cảnh.
  - Tự động dừng bay khi rê chuột (Freeze on Hover) và mở cửa sổ **Cyber Terminal Hacker** giả lập biên dịch khi nhấp chuột.
- 💌 **Thiệp chúc mừng cá nhân hóa (Personalized Wishing Card)**:
  - Cho phép người xem **nhập tên riêng** để lời chúc tự động cập nhật ngay lập tức.
  - Đổi lời chúc ngẫu nhiên (🎲) và sao chép lời chúc (📋).
- 🎵 **Nhạc nền thư giãn (Ambient Synthesizer)**:
  - Giai điệu piano / chime lofi du dương được tạo trực tiếp qua **Web Audio API** (chạy 100% offline, không phụ thuộc file mp3 ngoài).
- ✨ **Hiệu ứng đom đóm & Thả hoa**: Canvas particles phát sáng lung linh cùng tính năng thả cánh hoa rơi.
- 📱 **Tương thích Mobile 100%**: Đã được tinh chỉnh hoàn hảo cho iPhone, Android, Zalo và Messenger in-app browser.

## 🛠️ Công nghệ sử dụng (Tech Stack)

- **HTML5 & Vanilla CSS3**: Hiệu ứng chuyển động Keyframes, Glassmorphism, Responsive Media Queries.
- **JavaScript (ES6+)**: Bộ điều khiển tương tác, Canvas API, Web Audio API Synthesizer.
- **Python / Pillow / OpenCV**: Xử lý tách nền trong suốt và hiệu chỉnh độ tương phản logo Lab.
